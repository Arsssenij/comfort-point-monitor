# comfort-point-monitor

«Точка комфорта» — портативный монитор микроклимата в аудитории
Название
Разработка портативного монитора микроклимата «Точка комфорта»
Описание
Клиентский сегмент
Студенты, преподаватели и сотрудники ИШИТР, административно-хозяйственная часть.
Заказчик
ИШИТР ТПУ
Предпосылки
	Необходимость контроля температуры, влажности, CO₂ и освещённости в аудиториях.
	Влияние микроклимата на работоспособность и здоровье.
	Отсутствие недорогих портативных решений с понятным интерфейсом.
Роли/ТЗ
	Ведущий разработчик встраиваемого ПО (STM32/ESP32)
	Инженер-электронщик
	Разработчик мобильного/веб-интерфейса
	Тестировщик
Стек: C/C++, Python, ESP32, MQTT, JavaScript, SQLite/PostgreSQL, STM32/ESP32
Фреймворки: Arduino Framework, PlatformIO, React, FastAPI
Школа
ИШИТР
Курс
1-2
Цели проекта
	Цель проекта: Создать портативное устройство для мониторинга микроклимата в аудитории с отображением данных и уведомлениями.
	Цель бизнеса: Повысить комфорт и эффективность учебного процесса, обеспечить контроль параметров среды.
План работ
	Выбор датчиков (температура, влажность, CO₂, освещённость).
	Проектирование устройства и корпуса.
	Разработка прошивки.
	Реализация интерфейса отображения и передачи данных.
	Создание веб/мобильного приложения.
	Тестирование в аудиториях.
	Сборка и внедрение.
План внедрения
	Пилотное размещение в нескольких аудиториях.
	Сбор данных и обратной связи.
	Доработка.
	Масштабирование.
Ожидаемый результат
Работающее портативное устройство с датчиками, интерфейсом и системой уведомлений о микроклимате.
